# deck-docs - local cache of official-documentation findings

Per CLAUDE.md rule #2: when Claude consults official docs for a Steam Deck task, the key
findings get recorded here (with **source URL + date**) so future sessions don't re-fetch
the same thing. **Check here BEFORE searching/fetching the web.**

One file per tool/topic. Keep entries factual, quote exact wording where it matters, and
always cite the source + the date it was read (docs change).

This is the ONLY deck-docs cache. It lives inside the launchers repo
(`~/Emulation/tools/launchers/deck-docs/`), so it is git-tracked and covered by the normal
repo backups. Always use the absolute path `~/Emulation/tools/launchers/deck-docs/` when
citing or writing to this cache, from any working directory.
